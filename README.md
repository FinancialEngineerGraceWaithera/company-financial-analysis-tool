# Company Financial Analysis Tool

A Python-based financial analysis tool that uses company financial data to calculate key financial ratios and provide an easy-to-understand assessment of financial performance.

## Project Overview

This project analyzes the financial performance of an Irish company using financial statement data.

The current version uses **Datalex plc** as the example company and analyzes its **2024 financial year**.

The tool takes financial information such as revenue, assets, liabilities, equity, debt, cash flow, and market capitalization and uses this data to calculate financial ratios and generate a structured financial report.

## Features

The tool currently performs:

* Profitability analysis
* Liquidity analysis
* Leverage analysis
* Efficiency analysis
* Growth analysis
* Cash flow analysis
* Valuation analysis
* Working capital analysis
* Year-on-year comparison
* Overall financial interpretation
* Key financial findings
* Financial strengths and weaknesses

## Financial Ratios

The tool calculates:

* Profit Margin
* Return on Assets (ROA)
* Return on Equity (ROE)
* Current Ratio
* Quick Ratio
* Cash Ratio
* Debt-to-Equity Ratio
* Debt-to-Assets Ratio
* Asset Turnover
* Interest Coverage
* Price-to-Book Ratio
* Cash-to-Debt
* Cash-to-Assets
* Free Cash Flow
* Working Capital
* Revenue Growth
* Change in Net Income

## Error Handling

The project includes a `safe_divide()` function to prevent division-by-zero errors when calculating financial ratios.

If a calculation cannot be performed because the denominator is zero, the tool returns an appropriate "Not available" result instead of causing the program to crash.

## Example Company

**Company:** Datalex plc
**Financial Year:** 2024

The analysis uses financial data expressed in millions of US dollars.
